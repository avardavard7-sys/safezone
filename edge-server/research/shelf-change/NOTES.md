# Прямое свидетельство кражи: «с полки исчез предмет»

Прототип, в продукт не подключён.

Идея: сравнивать вид полки до и после того, как рядом был человек. Блоки 8×8, сравнение по структуре (NCC), а не по яркости; блоки под рамкой человека не учитываются; изменение должно держаться 4 кадра и быть рядом с кистью (≤ 0.10 кадра за последние 4 с).

Проверка 19.11.2026 на открытых роликах (в репозиторий не положены):
- A, B — постановочные кражи со стола в рюкзак (alich03/Shoplifting-Detection-using-yolov8, Samples/inputs)
- C — магазин, камера сверху (pyresearch/Shoplifting-Detection-using-Computer-Vision-and-Machine-Learning, demo.mp4)

| Ролик | Текущее правило ShelfWatch | Прототип |
|---|---|---|
| A | 0 тревог | 2 события, оба на месте взятого предмета |
| B | 0 тревог | 2 события, оба на месте взятого предмета |
| C | 0 тревог | 0 событий (что там взяли — неизвестно) |

Устойчивость на кадрах A и B, где человек стоит у стола и ничего не берёт: без изменений, свет ±25 %, шум — 0 ложных; движущаяся тень — 1 ложное на A.

Не работает: подвижная камера (ролик D дал 106 событий), мелкий товар на плотной выкладке с дальней камеры.

Запуск: `node pose.mjs <bridge> <кадры> <out.json>` → `python3 shelfchange.py <имя> <кадры> <out.json> '<полигоны>' <outdir>`.
