Редактор зон SafeZone

Нарисуй зоны мышкой — получи готовый zones.json. Работает офлайн, ничего никуда не отправляет.
📷
Перетащи сюда кадр с камеры
или кликни и выбери файл · можно вставить из буфера (Ctrl+V)
Кадр берётся так: docker exec safezone-bridge ls /tmp или скриншот из VLC
    Как рисовать: кликай по углам зоны (минимум 3 точки), потом «Сохранить зону».

    Важно: ставь точки по полу, а не по головам — система смотрит, где человек стоит.

    Зоны не должны накладываться друг на друга — иначе гость за столом посчитается ещё и гостем у стойки, и правила сработают крест-накрест.

    Для правила «бармена нет» нужны две зоны с одинаковым названием: гостей и персонала.
