# Что изменено в панели

## 🔴 Критично: RLS ломал вход и регистрацию

После включения защиты вход перестал бы работать вообще.

**`src/app/login/page.tsx`** — читал `profiles` **до** `signInWithPassword`,
то есть будучи анонимом. RLS такой запрос больше не пропускает, и вход падал
на «Пользователь не найден».
Исправлено: сначала вход, потом чтение своего профиля. Email и так строится
по шаблону `логин@safezone.kz`, профиль до входа был не нужен.
Побочная польза — исчез перебор логинов: раньше по ответу можно было узнать,
какие пользователи существуют.

**`src/app/register/page.tsx`** — проверял занятость логина прямым запросом к
`profiles`, тоже анонимом. Заменено на RPC `username_available(u)` —
`SECURITY DEFINER`, возвращает только да/нет, ни строк ни колонок не отдаёт.
Функция уже создана в базе.

## Переменные окружения

Добавь в `.env.local` и в Vercel:

```
NEXT_PUBLIC_BRIDGE_API=http://127.0.0.1:8099
```

Если не задать — используется это же значение по умолчанию.

## Важно про https

Панель на Vercel открывается по https, а бридж слушает http на localhost.
Браузер блокирует такие запросы (mixed content). Варианты:
открывать панель локально по http, либо поднять бридж с `API_HOST=0.0.0.0`
и ходить по IP машины, либо локальный https.
Это ограничение браузера, а не код.
